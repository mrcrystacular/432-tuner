👋 For grown-ups
  • Which string is #1? Hold the ukulele like you're going to play it. String 1 is the one closest to your face. String 4 is the one closest to the floor.
  • Higher = tighten the peg (wind the string tighter). Lower = loosen it. Small turns! A tiny twist goes a long way.
  • Pluck one string at a time and let it ring. Uke Buddy moves to the next string by itself once one is right.
  • Find a quiet spot and hold the phone near the ukulele.
  • New strings stretch and go flat for the first week or two, so it's normal to retune every time you play.
  • The little 🎤 bar shows how loudly Uke Buddy hears you. If it doesn't move when you pluck, check that the browser is allowed to use the microphone (iPhone: Settings → Safari → Microphone).
  • This uses standard tuning: G C E A (string 1 to string 4), with A = 440 Hz.
